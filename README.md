## 👋 About Me

I build **web and mobile products** end to end, from database and API design to the interface people actually touch.
My daily stack is the **TALL stack** (Tailwind, Alpine, Laravel, Livewire) for the web and **Flutter** for iOS and Android.

Right now I am building a **personal multi-agent AI system**: autonomous coding and automation agents that plug into my own development workflow.

```yaml
role:      Full-Stack Developer

```
